§0 · the situation

The display keeps blanking on taxi

You work on the line at Riga. A cockpit display goes dark for one second on taxi. The fault code will not clear.

Your team already ran the BITE test, changed the unit, and checked the wiring. Nothing fixed it.

The next step is a phone call to the OEM support desk.

OEM = the company that made the part
(ražotājs · производитель)

recurring = it keeps coming back
(atkārtojas · повторяющийся)

Your job on the call: explain the history · note the advice · agree the follow-up.

§1 · Dialogue 1 · listen first

Reporting the fault

AI have a recurring fault on a cockpit display.
BGive me the part number and the serial number first.
AIt blanks for about one second, then it comes back.
BIs the fault constant or intermittent?
AIt is intermittent. The code is DU-204, four times this week.
AAlways during taxi. We could not reproduce it parked.

LISTEN BEFORE YOU READ

Find three things: the fault code, how many times this week, and where it happens.

intermittent = on and off, not always
(ar pārtraukumiem · с перебоями)

reproduce = make it happen again
(atkārtot · воспроизвести)

§1 · Interactive · intermittent vs constant

See the fault — then name it

A steady line = a healthy display. A gap = the screen blanks.

Constant = broken all the time. Intermittent = broken only sometimes. More taxi vibration → more blanks, harder to reproduce.

§1 · Dialogue 1 · the history

The troubleshooting you already did

BWalk me through the troubleshooting you have done.
AYesterday we ran the BITE test, but it passed.
AWe cleaned the connector last night.
AWe fitted a spare LRU this morning.
AThe fault came back, so the root cause is the wiring.

PAST SIMPLE = FINISHED STEPS

Every step is done and closed. English marks it with the past form.

ran · cleaned · fitted · passed · came back

Time words: yesterday · last night · this morning.

§2 · Dialogue 2 · listen first

The radio that keeps failing

AA VHF radio fails the BITE test with a no-comm fault.
AAlthough we changed the antenna cable, the fault stayed.
AOn the bench it passed every time.
BThere is a service bulletin for this exact symptom.
BUnless the loom is damaged, the fix is a new backshell.
AIs there a workaround until the parts arrive?

LISTEN BEFORE YOU READ

Two questions: how long has the fault been there, and what passed on the bench?

workaround = temporary fix
(pagaidu risinājums · временное решение)

escalate = pass it up for more help
(nodot augstāk · передать выше)

§2 · Interactive · build the history

Report the steps in order — in the past simple

Each step is a finished action. Say it in the past simple as it appears.

ran → cleaned → swapped → checked. Then report the whole chain in one breath, like a real call.

§3 · vocabulary bank · 21 terms

Say the term for the meaning

The fault: recurring fault · intermittent · fault code · root cause · reproduce

The history: troubleshooting · BITE test · bench test · LRU · connector · wiring diagram

The advice: recommendation · workaround · escalate · service bulletin · follow-up

The paperwork: tech log · work order · part number · serial number

POINT & SAY

Teacher says the meaning → class says the term.

"A temporary fix?" → workaround. "A box you swap?" → LRU. "Keeps coming back?" → recurring fault.

§4 · grammar · the form

Past simple — the finished history

FormStructureExample
Positivesubject + past verbWe replaced the valve yesterday.
Negativesubject + did not + base verbWe did not replace the LRU.
Questiondid + subject + base verbDid you inspect the connector?
Short answerYes/No + subject + did / did notYes, we did. / No, we did not.

Irregulars from today: run→ran · come→came · find→found · send→sent · do→did.

§4 · common mistakes + pronunciation

Three errors to catch — and the -ed sound

✗ Yesterday we replace the valve.
✓ Yesterday we replaced the valve.

✗ We did not replaced the unit.
✓ We did not replace the unit.

✗ We replaced valve yesterday.
✓ We replaced the valve yesterday.

-ED HAS THREE SOUNDS

/t/  passed = "past"

/d/  cleaned = "cleend"

/ɪd/  fitted, recorded (extra syllable — only after t/d)

Do not add a vowel to every -ed.

§4 · Interactive · did the fault clear?

Before the repair vs after the repair

Before: the BITE test failed and the fault code was set.

After: we repaired the loom, the needle swings to CLEAR, no stored fault. Say it in the past simple.

§5 · Dialogue 3 · listen first

Confirming the follow-up

AWe found a chafed wire near the connector.
AWe repaired the loom. The fault code is now clear.
BRaise a work order, with the part number listed.
BNote the service bulletin reference against the task.
AIf the display blanks again, I will escalate it.
BWrite my recommendation in the tech log.

CONFIRM & DOCUMENT

Find three documents Ravil names.

work order · service bulletin · tech log

Read the advice back so nothing is missed.

§7 · speaking · role-plays in pairs

Make the whole call — four cards

Card 1 — Report: give the part & serial number, describe the recurring fault.

Card 2 — History: report the finished steps in the past simple.

Card 3 — Recommendation: understand it, repeat it back, ask for a workaround.

Card 4 — Follow-up: confirm the actions and the documents.

USEFUL PHRASES

"I have a recurring fault on…" · "Yesterday we ran the BITE test…" · "So your recommendation is to…" · "I raised a work order and recorded it in the tech log."

Swap roles after each card.
