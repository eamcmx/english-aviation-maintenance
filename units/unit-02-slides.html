§1 · the situation

A pair walkthrough on a Part-145 line

One mechanic reads the card aloud. The other does the work and confirms each step out loud. A single person's slip gets caught.

Four conditions before you sign off:

① every step complete, and done in order · ② the work matches the reference (AMM) · ③ any defect is recorded in the tech log and not signed off · ④ your entry is legible, dated and stamped.

§2 · Dialogue 1 · at the bench

Read a step → confirm it → query if unclear

AStep two: remove the access panel carefully, because eight fasteners secure it.
BThe access panel is removed, and all eight fasteners are collected in the tray.
AStep three: inspect the bracket for cracks…
BOne question, though. Which inspection lamp should I select?

The rhythm: command → confirmation → query.

A commands with the imperative. B confirms with a full statement. When a step is unclear, B queries it — never guesses.

Listen for the numbers: 8 fasteners · 25 newton metres.

§2 · Dialogue 2 · WARNING, CAUTION or NOTE?

Three boxes, three levels of risk

WARNING — risk to people. Ignore it and someone can be injured.
CAUTION — risk to the component. Ignore it and you damage equipment.
NOTE — helpful advice only. Never a safety instruction.

Second half: a defect is found → do not sign off the step until it is recorded in the tech log (not the work order), and the entry must be legible.

§2 · Interactive · triage the boxes

People, part, or just advice?

Click a line, then place it. The test is one question:

Is a person at risk → WARNING.
Only the part → CAUTION.
Nobody, just help → NOTE.

§2 · Dialogue 3 · line station, avionics unit

Same rhythm — a different specialism

AStep two: install the new unit. Seat it fully, then fit the four fasteners.
BInstalled, all four fasteners hand-tight, so it is ready for torque.
AObserve the NOTE: a functional test is required before we close the panel.
BRunning the built-in test — the screen reports no defect, so it is serviceable.

Sign-off chain: test passes → refit panel → verify seal → sign off each task → date + stamp → update tech log.

Torque here is 8 Nm in a cross pattern. The value always comes from the card and the AMM — never from memory.

§3 · vocabulary bank · 20 terms

Four families of task-card language

Documents: task card · work order · AMM · reference · tech log

Actions: inspect · torque · remove · install · sign off

Things: fastener · access panel · torque wrench · lockwire · bracket

Conventions: WARNING · CAUTION · NOTE · defect · step · legible

The headline collocations:

inspect for cracks · torque to a value · fit new lockwire

Every specialist word is glossed in the student bank — send learners there for anything new.

§4 · grammar in context

The imperative — the grammar of a step

PurposeFormExample
Commandbase verb + objectRemove the access panel.
Negativedo not + base verbDo not reuse the lockwire.
Orderfirst / then / nextFirst disconnect the plugs.
Conditionif / when + clauseIf the play is excessive, record a defect.

The card never says "you should remove" or "you must torque".

It says: "Remove the access panel."

Efficient, not rude — the priority is clarity. Pairs with Simplified Technical English for the writing task.

§4 · Interactive · fix the L1 errors

Three mistakes to drill out

Read the wrong line. Fix it aloud. Then reveal.

Latvian and Russian have no articles and build negatives differently — so the is dropped and do not is missing. Name the cause every time.

§4 · Interactive · torque to the value

Stop at the click — never estimate

The calibrated torque wrench clicks at the set value. That click is your confirmation.

Overtighten and the needle sails into the red — exactly what a CAUTION: do not overtighten prevents. Language: torque to the value, stop at the value.

§4 · Interactive · fit new lockwire

Always new — never the old wire

The wire twists between the bolt heads and pulls in the tightening direction, so a loosening bolt is resisted.

Card rule from Dialogue 1: fit new lockwire, never reuse the old wire — used wire is work-hardened and can fail.

§6 · speaking · role-play

Four cards · rotate every role

Card 1

Read the steps aloud, one at a time. Wait for confirmation.

Card 2

Confirm each step — or query it immediately.

Card 3

Report a defect. Explain why you cannot sign off.

Card 4: explain WARNING / CAUTION / NOTE to a trainee. Insist on the loop — a bare "yes" is not a confirmation; "Step two is complete" is. Circulate with the B2 speaking rubric (teacher key). No partner? Use the AI-partner prompts A/B/C.

§7 · writing + wrap-up

Write the defect · then the exit ticket

Task: a 4 mm crack on the flap track at Step 3 of card 27-51-11. Write a 4–6 line tech-log entry.

STE rules: short sentences · one instruction each · base verb · always the article.

Must state: card + step + reference · what & where · that the step is not signed off, and why.

Exit ticket: each learner names one condition that must be met before sign-off (Outcome 3).

Homework: finish the exercises · take the quiz.
