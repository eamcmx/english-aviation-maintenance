§0 · the scenario

On the flight deck, a stored fault is waiting

The BITE has stored a fault from the last flight. You and a colleague must read it correctly before you touch a single unit.

A code is only useful once you interpret it. First you name the system from the ATA chapter; then you name the suspect LRU; then you agree the follow-up action. You never remove a serviceable unit at random.

Warm-up — ask the room

· What is the first thing you do when the BITE shows a code?

· Why is it a bad idea to change a unit before you read the readout?

Take two or three answers in English. No wrong answers yet.

§1 · how a BITE maps a fault — fixed logic

Code → ATA chapter → system → LRU

The first digits are the ATA chapter. They name the system. The fault message then names the LRU — the line replaceable unit you can change on the line.

Same code, same meaning — always. That is why we say it with if + present.

Press a code. Read the chain aloud with the class.

§4 · grammar — the zero conditional

If + present, + present — a rule that is always true

If the code starts with 34, the system is navigation.

If the self-test passes, the readout shows no fault found.

Both parts are present tense. Never will in the if-clause. The same rule holds after when, as soon as, and unless.

Set the conditions → read the result aloud as an if-sentence.

§6 · AI conversation partner (Consultant stage)

A colleague who recasts your English

On the unit page, the chat partner plays your colleague on the flight deck. It speaks only at B2, keeps replies short, asks one question each turn, and gently recasts errors — watching your if-clauses.

Use it for early finishers or a learner without a partner.

What it will and won't do

✓ Play the colleague and push you to justify each step.

✓ Recast "if the code will start" → "if the code starts".

✗ It will not write your tech-log entry — it only asks a guiding question.

§7 · writing — a BITE fault-isolation log entry

Write it in Simplified Technical English

80–110 words. Give the fault code, the system, the suspect LRU, and the tests you ran. State the follow-up action.

Draft the first two lines now; finish for homework.

STE self-check

· One idea per sentence, under twenty words.

· Approved, plain words.

· Present tense in every if-clause — no will.

· State the follow-up action clearly, with if for the ground test.
