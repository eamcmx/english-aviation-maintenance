02 Latvian / Russian interference — why the errors happen

Indirect questions are hard for these learners for structural reasons, not carelessness. Name the cause when you correct — it makes the fix stick.

1 · The added do/does. ✗ …which effectivity does apply? → …which effectivity applies.

Latvian and Russian have no auxiliary do/does for questions or negatives. Learners meet English do-support, learn it is "needed for questions", and then over-apply it — even inside an embedded clause where English drops it. Fix: show that the main verb already carries the tense ("applies"), so does is redundant.

2 · Kept question inversion. ✗ …what is the current revision. → …what the current revision is.

Both L1s use relatively free word order and do not mark embedded questions with a fixed subject–verb pattern; the direct-question order simply carries over. Russian embedded questions keep the same order as main clauses, so "what is…" feels correct. Fix: drill the contrast pair aloud — direct inverts, indirect does not.

3 · Dropped whether / if. ✗ I want to know is my aircraft affected. → …whether my aircraft is affected.

Russian marks yes/no questions with the particle li or by intonation, and Latvian uses vai — but learners often omit the English conjunction because intonation alone felt enough in L1. Fix: teach whether/if as the obligatory bridge for every yes/no report; whether is safer before or not and in formal writing.

Two more to watch (pronunciation / lexis):
  • Reading digits. Both L1s group digits differently; drill "five-one-two-seven", not "fifty-one twenty-seven". Numbers are tested in the quiz.
  • False cousins. Actual ≠ current ("actual revision" is wrong — use current). Control ≠ check ("I control the effectivity" → "I check the effectivity").

03 Extension activities

  • Live call relay. Student A holds a work order; Student B is the OEM with a hidden effectivity list. A must find out if the aircraft is affected using only indirect questions. Swap.
  • Effectivity jigsaw. Give three groups different serial ranges and revision statuses. Each must decide "affected? mandatory? current revision?" then report to the class in three sentences.
  • Voicemail dictation. Play the OEM voicemail; students write the four changes (revision, current from when, extra serials, compliance level). Compare in pairs.
  • Rewrite for STE. Give a wordy real-style OEM reply; pairs cut it to Simplified Technical English — one idea per sentence, short sentences, active voice.
  • Cross-genre trace. Students follow SB 34-2189 across the SB, the AD notice, the work order and the tech log entry, and mark where each fact first appears.
  • AI partner call. Fast finishers use a chat prompt from the unit page to run a mock OEM call, then log two indirect questions they got right and one the AI recast.

04 CEFR B2 speaking rubric — role-plays

Score each learner once across a role-play card. Band 5 ≈ solid B2 / B2+, band 3 ≈ B1+ approaching B2, band 1 ≈ below B1. Give one focused piece of feedback per learner.

CriterionBand 5 (strong B2)Band 3 (developing)Band 1 (limited)
Range Uses unit terms (effectivity, compliance, superseded) and varied indirect openers accurately and flexibly. Core terms present; openers repeat ("could you tell me" only); some gaps. Few technical terms; falls back on direct questions and general words.
Accuracy Indirect questions in correct statement order; the three interference errors are absent. Mostly correct; one or two slips (a stray does, a missing whether) that do not block meaning. Frequent inversion / do-support / dropped whether; errors sometimes block meaning.
Fluency Speaks in a smooth flow; short natural pauses to plan; keeps the call moving. Some hesitation and reformulation; pace uneven but sustained. Long pauses; frequent stops that break the exchange.
Interaction Opens, gives the serial, questions, and reads the answer back; repairs misunderstandings; takes turns well. Manages the exchange but forgets to read back or confirm; occasional overlap. Relies on the partner to drive; little confirming or turn-taking.
Coherence Follows the 4-step call logic; connectors (although, unless, as soon as) link ideas clearly. Steps present but order wanders; connectors basic (and, so). Ideas listed with little linking; the call has no clear shape.
