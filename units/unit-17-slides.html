§1 · the situation

A two-technician IDG change at Riga

An A320, reg YL-BBX, is on jacks in bay two. The work order: change the integrated drive generator on engine one. The old unit is unserviceable; a fresh unit waits on the shelf.

You are the lead technician. First identify the part in the IPC. Then coordinate the removal. Then install, torque, tag and test — and sign the task card.

Four words before we start

IPC — the manual with drawings that show every part and its number.
IDG — the unit on the engine that makes electrical power.
Torque value — the exact tightness for a bolt, in newton metres.
STE — the plain rule for manuals: one instruction, verb first.

§2 · Listening · Dialogue 1 · find the part

Find the correct component in the IPC

Listen twice. Gist first (books closed): what is the job? Then detail: figure, item number, part number, effectivity.

Answers said in the audio: figure 24-11-01 · item 40 · part 761782C · effectivity lists tail YL-BBX. Click item 40 in the figure to confirm it is the generator.

§2 · Listening · Dialogue 2 · coordinate the removal

One calls the step — the other confirms

The removal sequence — verbs only

Disconnect the electrical connector → Fit the blanking cap → Remove the bonding lead → Cut the lockwire → Cap the oil lines → Remove the mounting bolt (last) → Lower the component on three.

Listen for how they warn before every move and confirm each one.

  • "Warn me before each move."
  • "Connector is off." / "Done, the cap is on."
  • "Hold the component firmly, because it is heavy."
  • "Lower the component together, on three."
§2 · Listening · Dialogue 3 · install, torque, tag, test

Torque to the value — then lock, seal and test

Start the bolt by hand → Torque to 34 N·m → Fit lockwire → Add a torque seal → Reconnect → Run a functional test → Sign the task card.

Set the target and press Torque: the wrench clicks at the set value. The exact value is the goal — not "as tight as possible".

§2 · Listening · Dialogue 4 · shift handover

The handover — listen for the figures

A voicemail to the next shift. Note the six facts the incoming technician needs.

Drill the phonetic tail: yankee-lima-bravo-bravo-x-ray = YL-BBX. Reading a registration back correctly is a real line skill.

Six handover facts

  • Job: IDG, engine one, tail YL-BBX
  • Part: IPC figure 24-11-01, item 40
  • Old unit unserviceable + warning tag
  • Torqued to 34 N·m with the torque wrench
  • Fresh lockwire + torque seal fitted
  • Functional test good → serviceable, card signed

§3 · Vocabulary · collocations

Verb + noun — say it as one chunk

VerbNoun partner
openthe IPC / a figure
checkthe effectivity / the part number
fita blanking cap / fresh lockwire
torquethe mounting bolt
runa functional test
signthe task card

Fast round: a noun → the collocation → a one-line instruction.

"torque wrench" → Set the torque wrench to 34.

Watch the article: Fit the blanking cap — never "Fit blanking cap". Latvian and Russian have no articles, so drill "the".

§4 · Grammar in context · the active imperative (STE)

Instructions are verb-first — not passive

STE rule: name the action, start with the verb. The doer "you" is understood.

The connector must be disconnected.

→ Disconnect the connector.

Keep the article — Install the pump. Use the plain verb — Remove the bolt, not "Removing".

§4 · Grammar · Latvian & Russian interference

Three errors to expect — and fix

Why it happensWrongRight (STE)

Calque of "it is necessary to…"It is necessary to torque the bolt.Torque the bolt.
Russian infinitive as a commandTo fit the blanking cap.Fit the blanking cap.
No articles in L1Fit blanking cap.Fit the blanking cap.

§6 · Speaking · role-plays · pairs

Four cards — swap roles after each

Card 1

Find the part in the IPC — agree figure, item, part number, effectivity.

Card 2

Coordinate the removal — call each step, confirm, warn before every move.

Card 3

Install, torque, test — state the value, fit lockwire + seal, confirm the test.

Card 4 — shift handover: summarise the job; confirm the old unit is unserviceable and the card is signed.   Assess with the B2 speaking rubric in the teacher key. Early finishers: the AI partner prompts on the page.

§7 · Writing · a task-card step list (STE)

Write the steps — verb-first, one per line

New component: a centre-tank fuel boost pump on an A320 is unserviceable. Write the change as a task card — 100–130 words, one instruction per line.

Cover: find in IPC (figure + item) · check effectivity · disconnect + blank · remove bolts · lower with two · tag u/s · install · torque · lockwire + seal · functional test · sign.

STE self-check

  • Every line starts with the action verb.
  • Active voice — no "must be" / "should be".
  • One instruction per line, kept short.
  • Ends with the functional test and the signed card.
Recap · exit ticket · homework

Name the part · say it verb-first · confirm on completion

IPC figure + item number names the part · an instruction is verb-first, active, with the article · on completion: torque to the value, tag unserviceable, run a functional test, then sign.

Exit ticket: one active-imperative instruction on a slip.   Homework: finish the 100–130-word task card; optional AI-partner speaking round.
