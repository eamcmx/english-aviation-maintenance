English for Aviation Maintenance · Unit 23 · CEFR B2 · EASA Part-66/145

Loading and verifying avionics software

Follow a software-load procedure, confirm each reference aloud, and prove the result — the language a mechanic and an avionics technician use around the dataloader.

90-minute class · balanced skills · read every reference back · "a finished bar is not a successful load"

By the end · the plan

Three things you will be able to do

1 — Follow a software-load procedure and confirm each step.

2 — Communicate part number, load number and configuration precisely.

3 — Verify a successful load, or troubleshoot a failed one.

Route: listen to three dialogues + a voicemail → mine the vocabulary → the once / when grammar → controlled practice → role-play the whole job → write the tech-log entry.

One habit throughout: say every reference out loud and ask "Do you confirm?"

§1 · warm-up

The scene: a comm radio needs new software

Two technicians work together at the rack. One drives the dataloader; the other reads the references aloud and watches the screen. Before anything runs, they must agree on every number.

Ask the room: what has to be TRUE before we press start? Collect answers — you will meet them again as the procedure.

§1 · before you listen · the four references

Catch — and read back — these four

§2 · Listening · Dialogue 1

Starting the load — catch the go/no-go words

"Let me read it back to confirm. Software part number 285-A047, revision C. Do you agree?"

"Since the card and the media agree, we are authorised to begin the data load."

Task 1 (closed): write the software part number, the load number, and the word that means "we can start".

Task 2 (open): find B's good catch about compatibility (mod 4 or later → the unit is mod 5).

§2 · Interactive · the load monitor

Run it, watch it, abort it — say the verb

Drive the load. Students supply the verb for each state: start · monitor · announce · halt · abort.

Inject a checksum error and it freezes — just like Dialogue 2. A clean abort keeps the old software safe.

§2 · Listening · Dialogue 2

A failed load — the trouble-shooting chain

"A checksum error indicates that the data is corrupted. The dataloader cannot trust the file."

"Yes, although you must check the label first. Unless the card matches exactly, do not use it."

Task: put the steps in order — abort · investigate · check the label · power cycle · re-read the checksum · restart.

Listen for the connectors: although, unless, because.

§2 · Interactive · checksum read-back

Read the checksum aloud — match or no match?

The card value is fixed on the left. Press Read checksum, read the display aloud, then decide.

Flip defective card and the values disagree — that is why the first load failed.

§2 · Listening · Dialogue 3

Verify and sign off — the golden rule

"A finished bar is not a successful load yet, because we still have to verify it."

"The report and the card agree on every field, so the verification is complete."

Task: list the verify steps in order — BITE · configuration report · cross-check · hardware line · power cycle · tech log.

Then feed the same job into the cross-check widget.

§2 · Interactive · cross-check

Card vs report — find the field that does not match

Match each field on the card to the report. A green link = agreed.

Toggle a mismatch and the sign-off is blocked until it is found and explained.

§2 · Listening · Track 4 (monologue)

Shift-handover voicemail — note the instructions

"Please inspect the load media carefully before you start, because last night one card produced a checksum error."

"Once the data load is complete, run the BITE test and open the configuration report."

Task: write the three things the next shift must do.

Notice the register: short, polite, one instruction per sentence — the model for the writing task.

§4 · Grammar in context · stage gating

once / when / as soon as — gate, then action

PatternExample
Once + past participle, + imperativeOnce loaded, verify the configuration.
Once + subject + present, + imperativeOnce the load finishes, run BITE.
When + subject + present, + imperativeWhen the light turns green, press start.
As soon as + subject + present, + imperativeAs soon as it starts, watch the bar.

The gate is present tense — no will inside it, even for the future.

§4 · Interactive · the stage gate

Open the gates in order — say each sentence

Each gate opens only when the one before it is done — that is what once / when mean.

Read the revealed sentence aloud, then say it again with a different connector.

§4 · Error clinic · Latvian / Russian

Three errors to catch before they set

✗ when the load will finish
✓ when the load finishes
L1 marks the future twice; English keeps the gate present.
✗ once configuration is verified
✓ once the configuration is verified
No articles in L1 — ask "which one?" to cue the.
✗ once loaded the software
✓ once the software is loaded
Restore the passive be and the subject.
Run E6 as a race.
Then feed back on one error type only — not all three at once.

§5 · Reading · authentic documents

Read a task card and a service bulletin for facts

E5 — Task card (AMM): power source, references, minimum mod, the abort rule, quarantine after two failures, where to record.

E7 — Service Bulletin (SB): the fault it fixes, mandatory?, the incompatible mod, the time, the task card, record retention.

Strategy: scan for the label or number; do not read every word.

The reading quiz uses fresh documents — a BITE readout, a MEL entry, a work order, an IPC.

§6 · Speaking · four role-plays

Rotate the four cards — lead and assist

Card 1 Start the load (you are A)
Card 2 Handle a failed load (you are B)
Card 3 Verify and sign off (you are A)
Card 4 Shift handover (off-going)

Rotate every ~3 min. Score with the B2 rubric in the key — range · accuracy · fluency · interaction · coherence. Hot-correct only the once/when tense.

§6 · Speaking · AI partner & pronunciation

Extra practice that talks back

The in-lesson partner stays in role, speaks at B2, asks you to confirm each reference, and recasts your errors gently.

Report back three recasts it gave you, and the rule behind each.

Pronunciation: record and compare the number strings — 622-1140-001, L-2231, 4F-2A-91-D0 — and the "th" in three.

§7 · Writing · Simplified Technical English

Write the tech-log entry (60–90 words)

Include: the unit + part number · software part number + load number · the steps you did · the BITE result · the verification result · name and date.

STE habits: short active sentences (≤20 words), one idea each, approved plain words.

"Run BITE" — not "it is necessary to carry out a BITE test." Start in class, finish for homework.

Recap · close

Say it, gate it, verify it, record it

Read every reference aloud and confirm · the once/when gate stays in the present · a finished bar is not a successful load until BITE is green and the report matches the card on every field · record the load and the result in the tech log.

Exit ticket: one correct once/when sentence about the load. Homework: finish the tech-log entry.
