E1  Gap-fill — one bank term in each gap

Terms must be exact. Accept the singular/plural or hyphen form only where the term itself allows it.

  1. airworthiness directiveOnly a mandatory order from the authority can force the job; there is none, so the bulletin stays optional.
  2. effectivityThe effectivity list is what you check to prove the job applies to this aircraft serial number.
  3. configuration controlTracing every change on paper so the aircraft record stays correct is configuration control.
  4. part numberYou confirm the part number against the bulletin before you fit any part.
  5. continuityAn unbroken electrical path is continuity; you test it on every pin.
  6. harnessA harness is the bundle of wires you route the new wire along.
  7. BITEBuilt-in test equipment is the unit's own self-test.
  8. deviationA small, recorded difference from the normal result is a deviation.
  9. modification statusPre-mod or post-mod is the modification status; you update it after the test.
  10. sign-offThe final signature that closes the job is the sign-off.

E2  Matching — term to plain meaning

  1. modification → eA change to the aircraft or its equipment.
  2. embodiment → hThe full act of carrying out a modification.
  3. service bulletin → gA maker's instruction to change or improve a product.
  4. task card → iA job sheet with the steps you must follow.
  5. wiring diagram → dA drawing that shows how the wires are connected.
  6. connector → cA plug that joins two parts of a circuit.
  7. software load → fThe act of putting new software into a unit.
  8. functional test → jA check that a system works correctly.
  9. snag → bA fault found on the aircraft.
  10. tech log → aThe aircraft's running record of work and faults.

E4  Grammar transformation — present perfect

Form = have/has + past participle. Watch the subject (have vs has) and the irregular participles.

  1. have embodiedPlural subject "We" takes have; participle of embody is embodied.
  2. has writtenSingular subject takes has; write → written (not wrote).
  3. have signed"I" takes have; sign is regular → signed.
  4. have completed"They" takes have; complete → completed.
  5. has loaded"She" takes has; load → loaded.
  6. have recorded"We" takes have; record → recorded.
  7. has updated"He" takes has; update → updated.
  8. has finished (or have finished)"The team" is one group, so has is standard; British English also allows have.
  9. have checked"You" takes have; check → checked.
  10. have not found (or haven't found)Negative = have not + participle; find → found.

E5  Reading 1 — Service Bulletin (six questions)

  1. b — no, it is optionalSection 1 says the bulletin is optional and no airworthiness directive applies.
  2. a — serial 4400 to 4600Section 1 gives the effectivity band; MSN 4471 falls inside it.
  3. b — 622-1140-002Section 3 names the new connector part number.
  4. b — below one ohmSection 3 sets the continuity limit at below one ohm.
  5. b — record a deviationMinus three is above minus five, so it is inside the limit: record a deviation, do not reject.
  6. a — sign the releaseSection 6 ends with signing the release, the last step.

E6  Error-spotting — correct the bold word

  1. has → haveSubject "We" takes have, not has.
  2. have finished … yesterday → finishedA finished-time word (yesterday) needs the past simple, not the present perfect.
  3. wrote → writtenThe present perfect needs the participle written, not the past simple wrote.
  4. have → hasSubject "She" takes has.
  5. record → recordedAfter have you need the participle recorded.
  6. check → checkedQuestion form: Have you + participle (checked).
  7. did → doneParticiple of do is done, not did.
  8. embody → embodiedAfter have you need the participle embodied.

E7  Reading 2 — Work order & tech log (six questions)

  1. b — twoThe work order links to task card 24-51-A and 24-51-B.
  2. a — below one ohmThe record states all continuity readings were below one ohm.
  3. b — no, it finished with no errorThe software load finished cleanly.
  4. a — inside the limitMinus three against a minus-five limit is inside the limit.
  5. b — post-modThe record states the modification status is now post-mod.
  6. b — review of the deviationThe release is ready after review of the recorded deviation.

  2. b — amberThe BITE shows one amber message.
  3. a — antenna gain lowB reads the message aloud: antenna gain low.
  4. a — minus threeThe gain reads minus three.
  5. b — minus fiveThe stated limit is minus five.
  6. a — yesMinus three is above minus five, so it is inside the limit.
  7. a — on the work orderB records the deviation on the work order with the exact reading.

Writing  Model completion report (annotated)

Target: 70–100 words, Simplified Technical English, present perfect for the reported result. The model below is exactly on-spec; the notes show why each choice is right.

Completion report — SB 24-51 embodiment

Aircraft MSN 4471. We have embodied service bulletin 24-51 on the number-two radio. We have fitted the new connector, part number 622-1140-002. We tested continuity on every pin. All readings were below one ohm. We have loaded software part number 285-A051. The software load finished with no error. The functional test passed. The BITE showed antenna gain minus three. This is inside the minus-five limit. We recorded an accepted deviation on the work order. The modification status is now post-mod. Configuration control is updated. Sign-off complete.

— A. Kalnina · 08 Aug 2026 · 92 words

Present perfect for the result now: "We have embodied", "We have fitted", "We have loaded" — the job is done and the result stands, so the present perfect is correct.
Past simple for a finished, timed step: "We tested continuity" and "All readings were below one ohm" — these describe completed measurements, so the past simple is right, not the present perfect.
Facts included (mark scheme): service bulletin + aircraft ✓ · connector part number ✓ · continuity result ✓ · software load + result ✓ · functional test + BITE ✓ · accepted deviation ✓ · modification status ✓ · sign-off ✓ · name + date ✓.
Simplified Technical English check. Every sentence has one idea and stays under 20 words. Active voice throughout ("We have loaded…", not "the software was loaded by us"). No long words where a short one works: "The software load finished with no error", not "The software loading procedure was successfully finalised without anomaly".
