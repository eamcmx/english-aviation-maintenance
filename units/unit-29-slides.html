Certifying release to service

§0 · the situation

End of the shift. The aircraft must be handed over.

A release to service is a promise in writing. You are declaring the aircraft airworthy, so the language must be exact, and nothing important can be left out.

Tonight you practise the handover: say what has been done, what is still open, and why the aircraft is safe to fly — so the release is quick and correct.

§0 · Interactive · what a release rests on

The basis for a release to service

A release is a checklist, not a feeling. Four things must be true before the certifying staff can sign.

Click each item on. The aircraft is only airworthy — and only then released — when all four are complete.

§1 · Listening 1 · Handing over a landing-gear job

Jānis (mechanic) & Elīna (certifying staff)

Jānis: I have finished the work order on the main landing gear.
Elīna: Has the functional test been passed?
Jānis: It has passed. The gear moved freely, and there was no leak.

Listen for: what was changed? was the old seal serviceable? what is still open?

Notice the habit: short sentences, one idea each, and the finished work stated impersonally.

§1 · Listening 2 · An independent inspection on a control run

Two people on a critical control

Anna: This is a control-cable job, so it needs a duplicate inspection.
Anna: Has the cable tension been set to the figure in the book?
Mechanic: The independent inspection is there to catch my mistakes.

Listen for: how many people? what approved data was used? where do the two signatures go?

The key idea: a critical control is checked twice, by two separate people.

§1 · Listening 3 · Justifying the CRS (+ voicemail)

Māris (supervisor) & Elīna (certifying staff)

Māris: Before you sign, tell me the basis for the release to service.
Elīna: All task cards are closed. All the independent checks are complete.
Elīna: The minimum equipment list lets us defer one reading light.

Listen for: is the aircraft airworthy with the light deferred? where is the deferral written? what is on the switch?

The voicemail hands the same aircraft to the next shift — one open item, paperwork nearly complete.

§1 · Interactive · from finished work to a signed release

The order a release happens in

A release is a sequence. Each step must be complete before the next, and a single missing signature holds the whole release.

Press run and watch the four steps: work done → independent check signed → documentation complete → certificate issued.

§2 · Vocabulary · release words

Twenty terms — meaning + collocation

release to service · certificate of release to service · airworthy · certifying staff · independent inspection · duplicate inspection · technical log · work order · task card · deferred defect

minimum equipment list · aircraft maintenance manual · functional test · serviceable · unserviceable · rectification · sign-off · traceability · scope of work · approved data

Say them aloud: C-R-S, M-E-L, A-M-M as letters. Stress: reLEASE to service, AIRworthy.

Collocations to keep: issue the CRS · carry out an independent inspection · run a functional test · declare it airworthy.

§2 · Interactive · the release voice

Says who did it, or says what was done?

A release is impersonal: the work is the subject, not the worker. Sort each line by its voice.

Then reword one active line the release way, using has been or have been + the past participle.

§3 · Grammar in context · present perfect passive

Say what has been done, not who did it

Subjecthave / hasbeenpast participleFull sentence
All checkshavebeencompletedAll checks have been completed.
The sealhasbeenreplacedThe seal has been replaced.
The defecthasbeendeferredThe defect has been deferred.
Both signatureshavebeenrecordedBoth signatures have been recorded.

The action is finished, and it still matters now — and we do not name the person. That is why a release lives in this one structure.

§3 · Interactive · build the passive

Subject + have/has + been + participle

Each build assembles the four parts of the present perfect passive. Watch where been sits.

The classic learner error is to drop been. In the passive it is never optional: have been completed, not have completed.

§4 · Reading · real documentation genres

Task card & certificate of release to service

Task card (E5): description → approved-data reference → numbered steps → functional test → sign-off → open item.

CRS + MEL (E7): work to approved data → cards closed → deferred item under the MEL → airworthy → signed by certifying staff.

Genre habits worth naming: every step is one action; the deferral is legal only with a MEL reference and a time limit; the sign-off closes the job. This is the Simplified Technical English you write in §6.

§4 · Interactive · legal to defer, or not?

Can it be deferred under the MEL?

A deferral is legal only when the minimum equipment list allows it, with a placard and a time limit.

Sort each defect. The MEL decides what may wait and what must be fixed before release.

§6 · Writing · Simplified Technical English

Write the release statement

Task: an A320 has had a nose-wheel tyre change on work order 5120. All task cards are closed. The independent check is done. One item is deferred — a cabin reading light, under the MEL for 10 days.

Write the CRS statement (about 60–80 words) in the present perfect passive.

STE rules: one idea per sentence · under 18 words · approved plain words · the unit terms · has been / have been + participle · do not name the worker · end with "released to service".

Recap · close

Work done → checked → documented → released

Run the functional test · carry out the independent inspection · complete the sign-off · check the MEL for any deferred defect · write it in the technical log · confirm the documentation · declare it airworthy · issue the certificate of release to service.
