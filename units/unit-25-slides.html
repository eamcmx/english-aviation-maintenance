English for Aviation Maintenance · Unit 25 · CEFR B2 · 90 minutes

Reporting a near-miss or hangar incident

Report a dropped-tool near-miss to the safety officer — a factual timeline, the past continuous for the background action, and one preventive suggestion, with no blame.

safety reporting · near-miss · root cause · corrective action  ·  "I was torquing when it slipped"

By the end · how the 90 minutes runs

Three outcomes — and the running order

1 · Report factually. Separate observation from opinion.

2 · Narrate in order. Use clear past-tense narration of the sequence of events.

3 · Suggest a fix. Propose corrective and preventive actions without blame.

Warm-up · talk in pairs

A tool falls two metres. It hits no one. Still a problem?

Yes — it is a near-miss. We report it even with no injury and no damage, because next time it could be worse.

Ask each pair for one word: what makes a dropped tool dangerous? (It can hit a person · it can damage the aircraft · it becomes FOD.)

§1 · vocabulary field · safety reporting

The words we will use all lesson

near-miss — almost caused harm, but did not · incident — did or could cause harm · hazard — could cause harm

root cause — the first, real reason · contributing factor — helped cause it, not the main reason

corrective action — stops it happening again · preventive action — stops it starting

lanyard · torque wrench · FOD · tech log · work order · debrief · mitigation · observation

Every hard word gets a plain gloss on first use, and lives in the vocabulary bank on the student page.

Watch the confusing pairs: near-miss ≠ incident · root cause ≠ contributing factor · corrective (after) ≠ preventive (before) · observation ≠ opinion.

§1 · Interactive · observation vs opinion

Fact or opinion? — sort each line

Only observations (facts) belong in the report timeline. Opinions and blame stay out.

Ask each pair to rewrite one opinion as a clean observation — "that stand is useless" → "the stand rail was loose."

§2 · Dialogue 1 · listening

"I have to report a near-miss immediately."

Mechanic: A tool just fell from my platform.

Safety officer: Is anyone actually injured?

Mechanic: Nobody — although it was extremely close, so I stopped the task at once.

Safety officer: Give me an observation, and not an opinion.

Mechanic: I was torquing the flap bolts when the wrench slipped out of my hand.

Listen for: Was anyone hurt? What fell? How far? What did the mechanic do first?

Professional moves: report at once · confirm no injury · observation, not opinion · sequence in order · barrier the area · log it.

§2 · grammar focus · past continuous

Background = was/were + -ing · Event = past simple

I was torquing the bolt when it slipped.

Long background action → past continuous. Short interrupting event → past simple.

Positive: I was standing on the platform.

Negative: I was not using a lanyard.

Question: Were you working under the flap?

§2 · Interactive · rAF · build the timeline

Place the event that interrupts the task

The background action was already in progress when the short event cut in — so it takes the past continuous.

Change the verbs and drag the marker; read the assembled sentence aloud with a partner.

§2 · Latvian / Russian speakers · recast

Three errors to catch — and fix gently

When it slipped, I torqued the panel. → I was torquing the panel. Background needs the past continuous.

We was working under the flap. → We were working under the flap. we / you / they → were.

I was work on the panel. → I was working on the panel. Keep the -ing ending.

§3 · Dialogue 2 · listening

"Let us find the root cause — not blame the last mistake."

Mechanic: The wrench slipped because my hand was tired.

Safety officer: Let us also look for contributing factors.

Mechanic: The light was poor, and the work order did not mention a lanyard.

Mechanic: The same stand had a loose rail last week in the tech log.

Safety officer: No lanyard, poor light and a shaky stand together caused this.

Listen for: the root cause vs the contributing factors — and the blame-free tone.

Root cause = weak tool control, not one tired hand.

§3 · concept

Keep asking "why?" until you reach the system

The tool fell → no lanyard → the work order did not require one → tool control was weak.

A contributing factor helped it happen. The root cause is the first, real reason — usually a weak system, not a tired person. That is why the report blames nobody.

§3 · Interactive · build the root cause

Stack the factors — reveal the root cause

One factor alone might not drop a tool. Together they overwhelm a weak system.

Ask: which single corrective action removes the most risk? (A tool lanyard — it stops the fall whatever else goes wrong.)

§4 · Dialogue 3 · listening

"What corrective action did the team agree on?"

Mechanic: Every tool above floor level must have a lanyard.

Mechanic: We will install better lighting under the flap.

Mechanic: We will repair the loose access stand.

Colleague: And what preventive action, before the next job?

Mechanic: Update the work order, so it requires a lanyard check.

Listen for: which actions fix THIS event (corrective) and which stop the NEXT (preventive).

Theme: fix the system, share the lesson, blame no one.

§4 · concept + Simplified Technical English

Corrective (after) vs preventive (before) — in STE

Corrective — repairs a known problem: fit a lanyard, repair the stand, add lighting.

Preventive — acts before any problem: update the work order to require a lanyard check.

Simplified Technical English: short sentences, one idea each, active voice, no vague words.

The tool was being dropped due to inadequate securing.
The tool fell. It had no lanyard.

§4 · Interactive · rAF · sort the actions

Corrective or preventive? — drop each action

Ask each time: does it fix a problem that already exists, or stop one that has not started?

The safest reports name at least one of each — repair now, and change the system for next time.

§6 · role-plays · pairs, swap roles

Give a factual timeline in past tenses.

Card 2 · Fact or opinion?

Card 3 · Root cause

Card 4 · Suggest an action

Swap roles after each card. Grade with the B2 speaking rubric (range · accuracy · fluency · interaction · coherence) in the key.

§7 · writing · Occurrence Report (STE)

Write it, then we close

90–120 words · location + type · sequence of events · immediate action · one contributing factor + one corrective action.

Self-check: observation apart from opinion · past continuous for the background · sequence in order · one factor + one corrective action.
