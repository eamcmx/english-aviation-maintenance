Simulation: avionics fault-find

A full troubleshooting run, spoken aloud with a partner. You begin from a BITE code, trace the WDM, isolate the LRU, and record the result in the tech log, exactly the way a real hangar team reasons through it.

VocabularyAvionics diagnosis, 20 terms GrammarSequencing diagnostic steps ScenarioA320 nav-display fault, line station SkillsListen · speak · read · write

By the end of this unit you can …

  • Can integrate BITE, WDM and troubleshooting talk to isolate an avionics fault.
  • Can narrate each diagnostic step clearly to a partner.
  • Can record the outcome and the next required action.

00The situation

It is the late shift at a line station, and a pilot has just written up a fault in the tech log.

The nav display went completely blank during the cruise, although it recovered once before failing again. The aircraft is now on the ground for a tight two-hour turnaround, so you and your partner must work quickly but methodically. First you interrogate the BITE self-test, because it usually names the fault before you touch anything. Then you trace the wiring through the WDM, unless the fault code already points straight to a single box. As you go, you check the harness, isolate the faulty section, and decide whether the LRU is genuinely defective. Finally, you write a clear tech-log entry and state precisely what the next team must do before flight. Study the three dialogues below, and then run the simulation yourself with a partner.

01Model dialogues

Listen first, before you read anything. After that, open the transcript and read along carefully. Notice how the two technicians name each diagnostic step aloud before they actually perform it, so that nothing is missed and nobody is caught out.

Dialogue 1, Reading the BITE code
Transcript

A: The pilot wrote up a nav display that went completely blank during the cruise, without any warning.

B: Understood. Before we assume anything, let us run the BITE self-test on the display unit.

A: The BITE has returned a single fault code, and it reads two-seven, F-C, one-one-four.

B: Good. That fault code points towards the data bus, rather than the display screen itself.

A: So the LRU behind the panel might be serviceable, although the signal is clearly being lost.

B: Exactly. Because a replacement box is expensive, we trace the wiring first. Bring the WDM.

A: The WDM is open, and it shows the display unit, the connector, and the data harness.

B: First, record the connector reference. After that, identify the pins that actually carry the data.

A: According to the diagram, the data travels on pin 4 and pin 5, through connector D-27A.

B: Good work. Note that the fault code also reports the signal loss as intermittent.

A: If the fault comes and goes, then a loose pin or a cracked conductor is likely.

B: Precisely. An intermittent fault is the hardest to catch, so we must work methodically.

A: Where should I begin the troubleshooting, at the connector or further along at the box?

B: Begin at the connector, since it fails more often. Later, we may measure the pin voltage.

A: Understood. I will isolate the faulty section step by step, and narrate every move to you.

B: Perfect. Read every step aloud as you go, because safety always comes before speed.

Dialogue 2, Tracing the wires
Transcript

A: I have set the multimeter to continuity, and I am ready to begin the continuity check.

B: Good, but first disconnect the connector, because you must never test a live circuit.

A: The connector is open and safe now, so I am probing pin 4 to the far end.

B: While you hold the probes steady, tell me what the multimeter reads for resistance.

A: The meter shows an extremely high value, which means there is no path at all.

B: That reading is a classic open circuit, so the conductor is broken somewhere in the harness.

A: Before I decide anything, let me test pin 5 as well, just to be certain.

B: Yes, because a single reading is never enough. Always confirm each pin separately.

A: Pin 5 is healthy. Its resistance is almost zero, so that conductor is clearly good.

B: So we have one open circuit on pin 4. Now we must locate exactly where it breaks.

A: There is a splice about halfway along the harness, so I will carefully open the tape.

B: Mind the shield as you cut, and do not nick the conductor underneath the insulation.

A: The splice looks badly burnt, and one terminal has partly slipped out of the connector.

B: That explains the intermittent signal. Now check for a short circuit and for a ground fault.

A: There is no short circuit between the pins, and no ground fault down to the airframe.

B: Good. Re-check the bonding strap as well, and then we can repair the splice properly.

Dialogue 3, Isolate the LRU and log it
Transcript

A: The splice is now repaired, so I have run the continuity check again on pin 4.

B: Excellent. And what does the meter read this time?

A: The resistance is close to zero, which shows a clean path from one end to the other.

B: So the harness fault is cured. However, we must still clear the LRU before we close up.

A: I have already re-fitted the connector and run the BITE self-test a second time.

B: Tell me, does the fault code return, or has it disappeared completely now?

A: The fault code has gone, and the BITE now reports a clean pass on the display unit.

B: Good, so the LRU was never faulty. The real problem lived in the harness all along.

A: That has saved us a new box, because the display unit is genuinely expensive to replace.

B: True. We isolated the actual fault, and that is precisely what careful troubleshooting achieves.

A: I will complete the tech log now. What exactly should I record as the action taken?

B: Keep it short but complete. State clearly what you found, and what you did about it.

A: I will write that I repaired an open circuit at the splice on connector D-27A.

B: Add the affected pins and the fault code too, so the next technician reads it quickly.

A: Done. I have logged the fault code, the pins, and the continuity check result.

B: Well done. Now sign it, date it, and we can finally hand the aircraft back.

Bonus listening, Shift-handover voicemail

02Vocabulary bank

These 20 terms are the working language of avionics fault-finding, and they are the only hard words in this unit. Each meaning is written in plain English, so that you can understand it without a dictionary. Every row also gives one example from the hangar and one common word pair, which is called a collocation.

TermPlain meaningExample at workCollocation
BITEBuilt-in test equipment: software inside the system that tests itself and reports any faults it finds.Always run the BITE first, because it often names the fault before you touch a wire.run the BITE
fault codeA code number that the BITE displays in order to identify which particular fault it has detected.Because the fault code points to the data bus, we suspect the wiring rather than the screen.read a fault code
WDMWiring diagram manual: the reference book that shows how every wire in the aircraft is routed.Open the WDM at the correct figure, so that you can trace the connector and its pins.trace the WDM
LRULine replaceable unit: a self-contained box that a technician can swap quickly on the line.Never condemn the LRU until you have traced the wiring that actually feeds it.swap an LRU
harnessA bundle of wires that are taped together and routed as one assembly through the airframe.The conductor is broken somewhere inside the harness, although the connector looks perfectly clean.a wiring harness
connectorThe plug and socket that join two harnesses, so that signals can pass between them.First disconnect the connector, otherwise you risk testing a circuit that is still live.disconnect a connector
pinA single metal contact inside a connector, which carries one signal or one supply.Probe each pin separately, because one healthy reading does not clear the whole connector.probe a pin
continuity checkA meter test that confirms whether a wire is whole and unbroken from one end to the other.The continuity check passed on pin 4, which proves the repaired splice now conducts.do a continuity check
open circuitA break in the conductor, where no current can flow because the path is interrupted.A very high reading with no path usually means an open circuit inside the harness.find an open circuit
short circuitA fault where two conductors touch, so the current follows a wrong and unintended path.Check for a short circuit between the pins before you refit the connector.a short circuit
ground faultA fault where a live conductor touches the metal airframe, which it should never do.There was no ground fault to the airframe, so the insulation is still sound.a ground fault
multimeterA hand-held meter that can read voltage, resistance and continuity, depending on the setting.Set the multimeter to continuity before you probe, otherwise the reading will mislead you.set the multimeter
pin voltageThe voltage measured at one particular pin, usually while the system is powered.Next, measure the pin voltage at the box, in case the supply itself is missing.measure the pin voltage
resistanceA measure, in ohms, of how strongly a conductor opposes the current flowing through it.Because its resistance is almost zero, that conductor is clearly healthy and unbroken.read the resistance
bondingA metal link that ties separate parts to a common ground, so that no charge builds up.Re-check the bonding strap as well, since a poor bond can imitate other faults.a bonding strap
shieldA metal wrap around a conductor that blocks electrical noise from reaching the signal.Mind the shield as you cut the tape, so that you do not nick the conductor.a cable shield
intermittent faultA fault that appears and disappears, which makes it far harder to locate and confirm.An intermittent fault often hides at a loose terminal, so inspect every contact carefully.an intermittent fault
spliceA joint where two conductors are permanently joined, usually crimped and then insulated.The splice looked badly burnt, which explained the loss of signal on that pin.repair a splice
terminalThe end fitting where a conductor is secured, either into a connector or onto a stud.One terminal had slipped out of the connector, so the contact became unreliable.a loose terminal
isolateTo narrow a fault down, step by step, until it sits inside one single component.We isolated the real fault to the harness, rather than blaming the expensive box.isolate the fault

03Grammar in context, sequencing diagnostic steps

A fault-find is a story that you must tell in the correct order, because a partner can only follow you if each step is named before it happens.

Look again at Dialogue 2, where the technicians use small linking words to mark the order of their steps. These words are called sequencing words, and they keep a shared job clear and safe:

“First, disconnect the connector.”

“Then find the pins that carry the data.”

“Next, measure the pin voltage.”

“Before we swap any box, we trace the wiring.”

“As soon as the meter is set, probe pin 4.”

Put the sequencing word at the start of the step, and follow it with a comma. Then use the plain imperative for the action, which means a base verb with no to in front of it.

StageSequencing wordsExample step
The first stepFirst, / To start,First, read the fault code.
The next stepNext, / Then / After that,Next, measure the pin voltage.
A step that waits for anotherOnce … / As soon as …Once the meter is set, probe pin 4.
The last stepFinally, / In the end,Finally, sign the tech log.

Common mistakes (Latvian & Russian speakers)

Latvian and Russian have no articles, and in both languages the verb after a modal takes no to. Because these habits carry into English, watch these three patterns very closely:

1
Next, measure pin voltage.
Next, measure the pin voltage.
English needs the before a thing that is already known. Latvian and Russian drop it, so remember to add it back.
2
First you must to open the connector.
First you must open the connector.
After a modal such as must, can or should, use the base verb alone, with no to.
3
At first, read the fault code.
First, read the fault code.
At first means “in the beginning, but it changed later”. For step one of a procedure, always say First.

E5 · Reading 1, AMM task card

Read the task card, then answer

AMM TASK 34-21-00-810 · NAV DISPLAY, FAULT ISOLATION · SUBTASK 05

Warning. Make sure the display unit has no power before you test, because a live circuit can injure you and can also damage the meter.

Procedure. First, read the fault code on the BITE, and write it in the tech log. Next, open the WDM at figure 34-21-14, so that you can find connector D-27A and the two data pins. Then disconnect the connector, and do a continuity check on pin 4 and pin 5.

A healthy wire shows near-zero resistance, whereas a high reading shows an open circuit inside the harness. If the wire is open, look for a burnt splice or a loose terminal, and repair it. After that, re-fit the connector and run the BITE again. If the fault code has gone, the LRU is serviceable, so do not change the display unit. Finally, sign the tech log, and record the next required action before flight.

Answer in one or two words.

  1. What must have no power before the test?
  2. Where do you read the fault code?
  3. Which two pins carry the data?
  4. What reading shows an open circuit?
  5. What two faults cause the open wire?
  6. If the fault code has gone, is the LRU serviceable?

1 the display unit · 2 the BITE · 3 pin 4 and pin 5 · 4 a high reading · 5 a burnt splice or a loose terminal · 6 yes, the LRU is serviceable.

Pilot report. The nav display went blank during the cruise. It came back once, and then it went blank again.

05Speaking, run the simulation

Work in pairs, and take one card each. Say every step out loud before you do it, and use the sequencing words from the grammar table above. Change roles when you finish, so that you both practise leading and following.

06Writing, a tech-log entry

Write the “action taken” entry for the fault-find you have just run, so that the next technician can understand it fast.

Task. Write 60–90 words in three short parts: fault found, action taken, and next action. Use Simplified Technical English habits, which means one instruction per sentence, the active voice, short sentences, and only approved words. Name the fault code, the connector, the pins, and the LRU status.

Model answer.

Fault found. BITE gave fault code 27-FC-114, display data loss. WDM traced to connector D-27A, data pins 4 and 5. Continuity check found an open circuit on pin 4. A burnt splice and a loose terminal were in the harness.

Action taken. The splice was repaired. The terminal was re-seated. The connector was re-fitted. The BITE was run again and gave a clean pass. The LRU is serviceable; the display unit was not changed.

Next action. Do one functional test before the first flight. If the fault returns, treat it as intermittent and re-inspect the splice.
