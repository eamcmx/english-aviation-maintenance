English for Aviation Maintenance · Unit 12 · Simulation day · CEFR B2

Simulation: avionics fault-find

From a BITE code, trace the WDM, isolate the LRU, and document the result — narrating each step clearly to a partner.

90-minute class · listening · vocabulary · grammar (sequencing) · reading · speaking · writing

By the end · how the lesson runs

Three outcomes — one simulation

Isolate. Integrate the BITE readout, the WDM and troubleshooting talk to isolate an avionics fault.

Narrate. Describe each diagnostic step clearly to a partner, in the correct order.

Record. Write the outcome and the next required action in the tech log.

Flow: listen to three dialogues → build the vocabulary → drill the sequencing grammar → read the documents → run the role-play → write the entry.

Balanced skills. The quiz at the end passes at 80%; the worked answers unlock after that.

§00 · the situation

Late shift · blank nav display · two-hour turnaround

The display went blank in the cruise. It came back once, then failed again — a classic intermittent fault.

You have two hours. Work quickly, but methodically: interrogate the BITE, trace the WDM, isolate the fault, and document it.

Elicit from the class:

• What do you check first?

• Do you change the box straight away?

• How do you find where the signal is lost?

§01 · Listening · Dialogue 1 — reading the BITE code

The code points to the wiring, not the screen

A: The BITE has returned a single fault code — two-seven, F-C, one-one-four.

B: That code points towards the data bus, rather than the display screen itself.

A: So the LRU behind the panel might be serviceable.

B: Because a replacement box is expensive, we trace the wiring first.

Listen for the figures:

One fault code · 27-FC-114

Data on pin 4 and pin 5

Connector D-27A · fault is intermittent

§01 · Interactive · the BITE self-test

Run the self-test — before and after the repair

The same BITE test both finds the fault and later clears it.

Unrepaired → fault code 27-FC-114. After the harness repair → a clean pass, which proves the box was never faulty.

§01 · Listening · Dialogue 2 — tracing the wires

Disconnect first · then probe each pin

B: First disconnect the connector, because you must never test a live circuit.

A: The meter shows an extremely high value — no path at all.

B: That is a classic open circuit. Now confirm pin five.

A: Pin five is healthy — resistance almost zero.

Safety: never test a live circuit — open the connector first.

Pin 4: very high reading = open circuit

Pin 5: ≈ 0 Ω = healthy

Cause: a burnt splice + a loose terminal. Now do E3.

§01 · Interactive · the continuity check

Probe a pin — read the meter

A high reading with no path is an open circuit. A reading near zero is a whole, healthy wire.

Probe pin 4 (broken) → O.L. · probe pin 5 → ≈0 Ω · repair the splice → pin 4 now ≈0 Ω.

§01 · consolidate · three faults to tell apart

Open · short · ground — and the safety rule

Open circuit
a break — no current can flow. Meter reads very high.

Short circuit
two conductors touch — the current takes a wrong path.

Ground fault
a live wire touches the airframe, which it never should.

Golden rule · disconnect the connector before any continuity test — never test a live circuit.

§03 · Grammar · sequencing diagnostic steps

Name each step before you do it

First, read the fault code.

Next, measure the pin voltage.

Once the meter is set, probe pin 4.

Finally, sign the tech log.

The pattern:

sequencing word + comma + base verb

No to after the imperative. "Next, measure…", not "Next, to measure…".

§03 · Interactive · order the fault-find

Put the steps in the right order

Click the steps top-to-bottom in the order a real fault-find happens.

Say each one aloud with its sequencing word. Then do E4 in pairs.

§03 · Common mistakes · Latvian & Russian

Three slips to watch

✗ measure pin voltage
✓ measure the pin voltage
A known thing needs the.

✗ you must to open it
✓ you must open it
A modal takes the base verb.

✗ At first, read the code
✓ First, read the code
At first = it changed later.

§01 · Listening · Dialogue 3 + shift handover

Confirm the fix · log it · hand over

A: The continuity check now passes on pin four — near zero.

B: And the BITE reports a clean pass. So the LRU was never faulty.

A: That saved us a new box. What should I record as the action?

B: State what you found and what you did. Add the code and the pins. Then sign and date it.

Result: harness fault cured; LRU serviceable.

Log: fault code + connector + pins + action.

Next: one functional test before the first flight.

Now do E8 with the transcript closed.

§04 · Reading · authentic documents

Read the task card & the tech log

E5 · AMM task card

A numbered fault-isolation procedure with a safety warning. Read for the pins, the meaning of a high reading, and the LRU decision.

E7 · Tech log + MEL note

The pilot report, the action taken, the next action — and when the display may be deferred under the MEL (category C, up to 3 days).

Answer in one or two words. Then discuss: defer, or fix now?

§05 · Speaking · run the simulation

Four role-play cards — narrate every step

1 · The technician

Hold the multimeter and the WDM. Narrate each step before you do it, and isolate the fault.

2 · The lead technician

Read the WDM, ask for each reading, and stop any unsafe step. Do not touch the tools.

3 · Shift handover

Brief the morning team in 60 seconds: fault code, what you found, what you did, next action.

4 · Talking to the pilot

Explain, calmly and clearly, that the fault was in the harness, not the box — and it is fixed.

Swap roles. Assess with the B2 rubric (range · accuracy · fluency · interaction · coherence).
