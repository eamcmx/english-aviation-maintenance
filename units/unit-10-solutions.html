E1 Gap-fill — put the right term in the gap Vocabulary

  1. BITE — Built-in test equipment is the on-board self-check; the collocation is read the BITE.
  2. self-test — The check a unit runs on itself; you run a self-test.
  3. fault code — The number shown for one fault, e.g. 34-12.
  4. readout — The message on the screen that you read and interpret.
  5. LRU — A line replaceable unit — a box you change on the line.
  6. system — The aircraft area a code names, e.g. navigation.
  7. ATA chapter — The standard chapter number that names each system.
  8. CMC — The central maintenance computer collects every fault code.
  9. ECAM — The screen that shows warnings to the flight crew.
  10. connector — A plug that joins a unit to the aircraft wiring.

E2 Matching — term to meaning Vocabulary

  1. fault message → the line of text that names the fault and the unit — It identifies both the fault and the affected LRU.
  2. maintenance message → a stored message for maintenance, not shown to the crew — For maintenance only; the ECAM is the crew display.
  3. no fault found → the result when the test finds nothing wrong now — The test detects nothing at this moment; the fault may still be intermittent.
  4. ground test → a test of a unit on the ground to repeat the fault — Run on the ground to try to make the fault reappear.
  5. fault isolation → the step-by-step method that narrows a fault to one unit — A systematic method, not a single check.
  6. confirm → to prove that a fault is real, not a false reading — Proving the fault is genuine, e.g. the CMC repeats it.
  7. isolate → to narrow the fault down to one unit or area — Narrowing down; the result of fault isolation.
  8. reset → to switch a unit off and on to clear a fault — Power-cycle to clear a temporary fault.

E3 Dialogue completion — the flight-deck talk Vocabulary

  1. BITE — You read the BITE readout on the flight deck.
  2. fault code — 34-12 is the number for the fault.
  3. LRU — ADIRU 1 is the suspect line replaceable unit.
  4. self-test — Run again in case the fault is intermittent.
  5. readout — The screen still shows the same code.
  6. intermittent — Shows in flight but hides on the ground = comes and goes.
  7. serviceable — If the connector is the cause, the computer itself is still fit to use.
  8. isolate — Narrow to ADIRU 1, then bench-test it.

E4 Grammar transformation — the zero conditional Use of English

  1. shows — Present simple, third person -s; the BITE shows.
  2. starts — Fixed rule → present tense, -s for the code.
  3. passes — -es after -ss: the self-test passes.
  4. repeats — Third-person -s: the CMC repeats.
  5. fails — Present, -s for the ground test.
  6. clears — Present, -s for the reset.
  7. is — be → third-person present is.
  8. says — Present, -s for the readout.
  9. looks — Present, -s for the connector.
  10. fails — Present, -s for ELAC 1.

E5 Reading 1 — CMC post-flight report Reading

  1. the CMC (central maintenance computer) — Stated in the first line: it collects every fault code.
  2. 34-12-34 — The first fault code named in the report.
  3. navigation — Code starts with 34, and 34 is the ATA chapter for navigation.
  4. ADIRU 1 — The fault message names the number one air data unit.
  5. no fault found — If the self-test passes, the readout shows no fault found and the message clears.
  6. the tech log — Last line: record every code and action there.

E6 Error-spotting — fix eight errors Use of English

  1. If the BITE shows 34, the system is navigation. — Present tense in the if-clause, never will.
  2. If the code starts with 22, the system is autoflight. — Add the article the.
  3. If the self-test passes, the readout shows no fault found. — No will; present tense after if.
  4. If the CMC repeats the code, the fault is confirmed. — Add third-person -s.
  5. When you read the readout, note the fault code. — Present tense after when, no will. (as soon as also accepted.)
  6. If the BITE shows a fault code, the technician reads it. — English needs the articles the and a.
  7. If the ground test fails, the LRU is not serviceable. — Present tense in the if-clause, no will.
  8. If the reset clears the code, the fault is gone. — Add third-person -s.

E7 Reading 2 — Trouble Shooting Manual task Reading

  1. 22-83 — The fault code the TSM task addresses.
  2. autoflight — 22 is the ATA chapter for autoflight.
  3. FMGC 2 — The message names the number two flight management computer.
  4. no fault found — the fault is intermittent — A clean ground test means it did not repeat now; it comes and goes.
  5. reset the unit and run the self-test — If a pin is loose, reset then re-test before blaming the LRU.
  6. the tech log — Record the code and the action there.

E8 Listening review — Dialogue 3 Listening

  1. 27-93 — The fresh BITE code in Dialogue 3.
  2. flight controls — 27 is the ATA chapter for flight controls.
  3. ELAC 1 — The message names the number one flight-control computer.
  4. the self-test — They run it first, in case a reset clears the fault.
  5. no, it does not — After the reset the BITE still shows 27-93.
  6. the connector — They isolate ELAC 1 and inspect its connector.
  7. no, it is not serviceable — Connector is clean, so the computer itself is the root cause.
  8. to the bench for a ground test — ELAC 1 is sent for a thorough ground test.

WRITE Model answer — a BITE fault-isolation log entry Writing · STE

A model tech-log entry (about 95 words) in Simplified Technical English (ASD-STE100). Read the annotations for what makes it work at this level.

TECH LOG ENTRY — BITE FAULT — ADIRU 1
Fault code: 34-12-34. If the code starts with 34, the system is navigation.
Fault message: ADIRU 1 FAULT. The suspect LRU is the number one air data unit.
Test 1: run the self-test. The self-test repeats the code, so the fault is confirmed.
Test 2: open the CMC. The CMC lists the same fault three times today.
Test 3: check the connector. The connector is clean and tight.
Result: ADIRU 1 is the suspect unit. Next step: run a ground test on ADIRU 1.
If the ground test fails, ADIRU 1 is not serviceable. Fit a serviceable unit.
Zero conditional, present + present: "If the code starts with 34, the system is navigation." No will, correct -s.
STE — one idea per sentence: each line carries a single instruction or fact; every sentence is under twenty words.
STE — approved plain words & articles: "run", "check", "fit"; "a serviceable unit", "the connector" — articles present, as English needs.
Task coverage: gives the code, the system, the suspect LRU, the three tests, and the follow-up action with an if-clause for the ground test.
✓ Short sentences, plain words
✓ Fault code, system, suspect LRU
✓ Present tense in every if-clause, no will
✓ Follow-up action stated, with if for the ground test

Marking note: award for accurate zero conditionals, correct specialist terms and collocations, STE brevity, and a clear follow-up decision.
