§1 · the situation

Two codes, one shared language

The task card says P12. The phone makes it sound like TP12. One is the connector, the other is a single test pin inside it.

Nobody on the line is a native English speaker. You cannot lean on perfect grammar. You lean on three strategies — paraphrase, confirm, check back — before the wrong pin ever goes into service.

§2 · Dialogue 1 · The connector reference

Catch the misunderstanding, then repair it

A: The reference on the task card is P12. That is a single pin, isn't it?

B: No, not exactly. P12 is the connector, although TP12 is the test pin.

A: Allow me to paraphrase it, to confirm I understood you.

B: Please do. It is safer if you repeat it back in your own words.

LISTEN FOR

  • the tag that asks for a yes
  • the correction with although
  • the paraphrase back
  • the spell-out: Tango, Papa, one, two
§2 · Dialogue 2 · Hangar talk & a BITE readout

Casual talk, formal record

B: Reseat the connector, then run the BITE test again. Reasonably straightforward, yeah?

A: In the tech log I record it formally, not in this casual register, right?

B: Correct. Conversation stays casual, although the written record stays formal and clear.

TWO REGISTERS

Hangar talk — short, easy, friendly. Still confirm the code.

Tech log — formal, precise, permanent. No slang.

§2 · Dialogue 3 · Confirming the fix with the lead

Report it, confirm it, sign it back

Lead: There was a misunderstanding over the reference. You resolved it with the OEM, didn't you?

Tech: Yes. I read back each code in the phonetic alphabet, to prevent any mistake.

Lead: That is the check back we require on a safety-critical reference.

THE SAFETY CHAIN

  1. Call the OEM & clarify
  2. Paraphrase back
  3. Read back (phonetic)
  4. Diagram vs part number
  5. Formal tech-log entry
§3 · Interactive · the clarification loop

State → tag → wait → confirm (or repair)

The four moves that stop you acting on a guess. If the answer is a clear yes, the loop closes. If it is no, you paraphrase and go round again.

This is what "check back" means in practice — a routine, not a feeling.

§5 · Interactive · grammar — question tags

Positive statement → negative tag, and vice versa

The tag reuses the same helping verb and tense as the statement. No helping verb? Use do / does / did.

Casual talk allows a universal right?. A formal report expects the matched tag: isn't it? · didn't you? · won't you?

§5 · grammar — Latvian & Russian interference

Three tag errors to pre-empt

Heard from studentsCorrectWhy it happens
It is the correct pin, no?…, isn't it?L1 uses one frozen tag (да? / vai ne?). English changes the auxiliary.
You sent the report, isn't it?…, didn't you?Tag must match verb & tense — here sent → did.
That is not the pin, isn't it?…, is it?Negative statement takes a positive tag — flip the polarity.
§6 · Interactive · spell out & read back

Make P and T impossible to confuse

Type a reference and read it back the safe way. On a noisy line P and T collapse into each other — Papa and Tango never do.

Try TP12, then P12. Then spell your own stand number aloud.

§7 · Interactive · switch register

Same fact, two registers

Drag from casual hangar talk to a formal tech-log line. The facts do not change — the words do.

Formal markers: full forms, precise nouns, the plain past (reseated the connector). No slang, no mate.

§10 · writing — STE tech-log entry

Write it clean (ASD-STE100 habits)

Task. A BITE readout showed TP12 open. You called the OEM, cleared the misunderstanding, and reseated the connector. Write the tech-log entry (60–90 words): fault → how you confirmed meaning → fix. Formal register.

  • One idea per sentence.
  • Short, common words.
  • Same word for the same thing.
  • Under 20 words a sentence.
  • Plain past, not passive.
§11 · wrap-up

Never assume — always check back

State the fact. Add a tag. Wait for a clear yes. Paraphrase if it is no.

Exit ticket: each student says one confirmation tag and one strategy verb aloud. Then the quiz consolidates listening, reading, use of English and vocabulary.
