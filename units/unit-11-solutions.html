Teacher · gated · full model answers

E1 · Gap-fill

Put the correct bank term into each gap.

  1. wiring diagram — it is the master drawing you open before tracing any conductor.
  2. connector — each one carries a unique code (P1, J12) so nobody confuses them.
  3. pin — a pin is a numbered male contact; W241 lands on pin 3.
  4. socket — the female cavity that receives a male pin when the halves mate.
  5. continuity — the test confirms an unbroken path between both ends.
  6. harness — the bundle of conductors routed together behind the panel.
  7. plug — technicians back-probe the mating plug, not the socket contacts.
  8. resistance — infinite resistance on the meter signals an open circuit.
  9. multimeter — the tool set to the continuity range before probing.
  10. routing — the path the conductor takes along the loom past the clamps.

E2 · Matching

Match each term to its correct meaning.

  1. contact → the metal part that carries the current general word for the pin or socket that conducts.
  2. open circuit → a complete break, so no current can flow "open" = the path is broken end-to-end.
  3. short circuit → an unwanted path, usually to ground current takes a wrong route, normally to the airframe.
  4. terminal → a point where a conductor is fixed and connected e.g. a terminal block where wires are secured.
  5. receptacle → the fixed connector half, mounted on a unit the half that stays on the equipment; the plug enters it.
  6. insulation → the protective cover around a conductor when chafed it can cause a short to ground.
  7. ground → the return path to the airframe, at zero volts the reference the current returns to.
  8. bonding → a low-resistance link between equipment and airframe a bonding strap keeps resistance to structure very low.
  9. shield → a metal braid that blocks interference surrounds a conductor to protect the signal.
  10. splice → a joint where two conductors are joined a permanent join, re-made if it goes loose.

E3 · Dialogue completion

One word in each gap.

  1. open no continuity + lamp off = a suspected open circuit.
  2. short a conductor touching the airframe is a short, not an open.
  3. resistance a short reads near zero resistance to ground.
  4. pin a backed-out pin interrupts the electrical path.
  5. plug you re-seat the contacts inside the plug.
  6. insulation you inspect the insulation for chafing.
  7. ground chafing near the structure causes a short to ground.
  8. continuity first test continuity from P1 to J12.

E4 · Grammar transformation — prepositions of position and path

Add the correct preposition.

  1. from "from" marks the start of the path.
  2. to "to" marks the end of the path.
  3. through passing inside the panel = "through".
  4. on (or at) a contact sits on/at a pin, never "in".
  5. out of leaving the plug = "out of".
  6. into entering the connector = "into".
  7. along following the length of the harness = "along".
  8. on (or at) the bonding strap is fixed on/at pin 4.

E5 · Reading 1 — AMM task card

AMM 32-61-00 · Task card 4 · gear-down warning fault isolation.

  1. W241 the card isolates that single conductor.
  2. pin 3 (3) W241 originates at pin 3 on P1.
  3. continuity the multimeter must be set to the continuity range.
  4. no continuity an open circuit reads no continuity whatsoever.
  5. the insulation (insulation) you inspect insulation for chafing near clamps/brackets.
  6. the tech log (tech log) the complete result is recorded in the aircraft tech log.

E8 · Listening review — Dialogue 3

Replay Dialogue 3, then answer.

  1. an open circuit A suspects an open because the lamp is dead.
  2. no continuity the meter reads no continuity between P1 and J12.
  3. an open circuit infinite resistance normally confirms an open.
  4. continuity a backed-out contact interrupts continuity.
  5. ground a short reads near zero resistance to ground.
  6. the tech log B will write the investigation up in the tech log.

Model writing answer — tech-log corrective action (annotated)

ASD-STE100 Simplified Technical English · ~90 words. The learner's version may differ; grade against the four self-check lines, not this wording.

Model — Corrective action

Traced wire W241 on the wiring diagram. The conductor runs from pin 3 on connector P1 to socket B on connector J12. Did a continuity test with the multimeter. The test showed an open circuit. The resistance read infinite from P1 to J12. Inspected the harness. Found chafed insulation near the clamp. Found no short circuit to ground. Re-seated the pins in the plug. Re-made the splice at terminal block TB2. Confirmed the bonding on pin 4. Re-tested the system. Continuity is now good. The lamp illuminates. Returned the aircraft to service.

Why this is a strong STE answer:

Short sentences, one idea each. Every sentence is under 14 words. "Inspected the harness." and "Re-tested the system." each carry a single action — easy to read under pressure.
An action verb starts each step. Traced… Did… Inspected… Re-seated… Re-made… Confirmed… Returned… The reader sees the sequence at a glance.
The path is exact. from pin 3 on connector P1 to socket B on connector J12 — connector, pin, socket and "from … to" leave no ambiguity about the route.
Result then next action. The entry states what the test showed (an open circuit, resistance … infinite) before each corrective step, so the logic is traceable.
No hedging, no long clauses. STE avoids "which", "although" chains and passive padding here. Numbers and codes (W241, P1, J12, TB2, pin 4) are written exactly.

Common learner slips to correct on the draft: "runs to P1 to J12" → from P1 to J12 · "on pin 3" is fine, "in pin 3" is not · "trough" → through · long sentences joined with "and … and …" → split into single-idea steps.
